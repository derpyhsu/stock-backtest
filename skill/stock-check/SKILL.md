# stock-check：個股健檢

使用者要的是**紀律和回測**，不是心得。回答只能來自下面的流程，不要用「題材好」「基本面不錯」這種沒有回測支撐的話。

## 流程

1. **跑健檢**：`python3 scripts/stock_check.py <代號> [持有成本]`（約 5～10 分鐘）。它會：
   - 列出現況：120 日高點回撤、20 日均線上／下、最新已公布月營收年增、外資 20 日買賣超、融資 20 日增減。
   - 在全市場 2022 年以來的資料裡找「同組」的股票-日，由寬到嚴：回撤＋趨勢 → ＋營收 → ＋外資 → ＋融資。
   - 列件數、60 日平均（扣成本）、勝率、超額（減同日全市場平均）、**每月一票超額**、逐年超額，並判定「有優勢／無優勢／劣勢／樣本不足」。
   - 另做一份「長期持有」（250 個交易日）判定，標準相同；使用者問能不能長期抱時，以這份為準。
   - 查是否在今日候選、今日訊號、模擬帳戶裡。
2. **用判定回答，不要改寫結論**：
   - 判定看「最嚴且樣本 >= 30」那一層。
   - 「有優勢」要同時滿足：樣本 >= 100、每月一票超額 > 0、至少六成年份超額 > 0。只有全部事件的平均好看不算（常常是單一崩盤後反彈灌出來的）。
   - 持有成本是沉沒成本，只用來報損益，不影響結論。
3. **給具體動作和價位**：
   - 有優勢：可續抱，用系統停損 -15% 和 60 日期限。
   - 無優勢／劣勢：腰斬（回撤 <= -45%）的照 `results/腰斬續抱/` 的回測，「收盤站回 20 日均線隔天賣；從判定當天收盤再跌 15% 停損；最晚 60 個交易日」（停損讓平均幾乎不變，但最差一筆從 -48% 降到 -23%）；其他情況照停損或 60 日期限出場，不攤平。
   - 新資金照系統規則：模擬帳戶 v5（營收加速＋一年新高＋處置股）的訊號、0050 定期定額。
4. **特殊情況才另做回測**：問題超出上面的分組（例如「哪個價位賣」「要不要加碼」），先寫成規則，放 `scripts/`，用同樣的超額、每月一票、逐年標準驗證，結果存 `results/<主題>/README.md`。
5. **ETF 或上市未滿一年的股票**：樣本不足，直接說回測不了，只列上市以來含息報酬、最大回撤，和 0050、00878 同期比較。

## 回覆格式

- 第一句是規則給的動作（續抱／賣出條件與價位／不買）。
- 一個表：相似條件、件數、60 日平均、每月一票超額、判定。
- 最多三點說明（為什麼這層、樣本是否集中在某次崩盤、系統狀態）。
- 結尾一句「依回測規則，非投資建議」。
- 不放新聞、不用「我覺得」。使用者要新聞或消息面時，才照 `skill/agent-review` 查。
