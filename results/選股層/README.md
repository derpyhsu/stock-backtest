# 選股層：先挑對股票，再談買點（2026-11-27）

起因：影片教的買點套到全市場幾乎都和隨機買差不多。使用者認為問題在「挑的標的」，所以把影片裡「挑哪些股票」的條件單獨拿出來測。

條件定義：
- 熱門：當天成交值排全市場前 100 名。
- 大盤好：加權指數在月線上，而且月線上揚。
- 主流領頭：近 20 日漲幅前 5 名的產業裡，該產業漲幅前 3 名的股票。
- 近期創一年新高：近 20 天內收盤創過 240 日新高。

## 1. 池子本身（`selection_layer.txt`，腳本 `scripts/selection_layer_test.py`）

60 天、扣成本、和同一天全部有量股票的平均比：

| 做法 | 筆數 | 比隨機 | 贏的年數 |
|---|---|---|---|
| 三條件都符合，待在池子裡的每一天 | 1,971 | +9.0% | 5/5 |
| 三條件都符合，第一天進池子才算一筆 | 613 | +5.4% | 3/5（2022 -1.1%、2026 -2.2%） |
| 同上，而且近期創過一年新高 | 414 | +7.6% | 3/4 |
| 同上，但近期沒創一年新高 | | -1.3% | |
| 大盤不好時 | | -0.1% | |

好處幾乎都在「同時也創一年新高」的股票上，也就是它和現有的一年新高訊號重疊很大。

## 2. 池子裡再套影片買點（`../選股影片規則/nocc_universe.txt`）

回後買上漲、盤整突破等買點放進池子裡，比「池子裡隨便一天買」差 1.0%~2.4%。買點沒有加分。

## 4. 放進 v5 帳戶（`account.txt` 下半，腳本 `scripts/selection_layer_account_test.py`）

2023-04-06 ~ 2026-11-26，報酬／最大回撤：

| 做法 | 全期 | 前半 | 後半 |
|---|---|---|---|
| A 現在的 v5 | +228.5%／-18.3% | +61.2% | +104.2% |
| B 一年新高：成交值前 100 的先買 | +254.5%／-20.2% | +57.3% | +126.4% |
| C 前 100 而且主流領頭的先買 | +226.1%／-18.5% | +61.0% | +103.0% |
| D 一年新高：只買成交值前 100 | +245.7%／-19.0% | +70.0% | +104.3% |
| E 只在大盤好的日子買 | +228.6%／-17.8% | +57.9% | +108.1% |
| F 加三條件池的股票，排最前 | +209.8%／-21.7% | +63.5% | +89.0% |
| G 加三條件池的股票，照原排序 | +199.8%／-18.6% | +57.2% | +90.8% |

D 是唯一前後半都不輸 v5 的（逐年 2023 +22.3%、2024 +41.6%、2025 +24.9%、2026 +59.9%，v5 是 +21.9%、+33.8%、+25.5%、+59.2%），
一年新高那份的勝率 41%→47%、平均每筆 +13.0%→+18.2%。但領先主要來自 2024 一年，回撤略大。
成交值名次換別的數字是否還成立見 `account_topN.txt`（`scripts/selection_layer_topn_account_test.py`）。

## 結論

- 影片裡有用的是「挑哪種股票」（熱門、創新高、大盤好），不是「哪一刻買」。
- 三條件池另外加進帳戶反而變差（F、G），因為和一年新高重疊，多出來的是比較差的那些。
- 「一年新高只買成交值前 100」是候選改動，還沒採用。要注意 2023~2026 是大型 AI 股行情，成交值大的股票本來就佔便宜；2022 空頭年還沒有資料可驗。

「只買前 N」不穩：只有 100 這個數字贏，換 50、150、200、300 或換成平均成交值都輸或平手，是剛好挑到的數字，不採用。
「前 N 的先買」（不排除別的，只是同一天多檔時熱門的排前面）三個數字全期都贏 v5，但贏的都在後半（2025、2026），前半平手或小輸，回撤多 1~2 個百分點。
還沒達到「前後半都贏」的標準，列為候選，等 2022 空頭年資料補完再驗一次。v5 不改。
