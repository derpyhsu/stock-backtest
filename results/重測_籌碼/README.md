## 結論

- **v2 不加籌碼訊號**：混入 v1 後報酬從 +129% 掉到 +41%、回撤從 -28% 變 -41%；籌碼策略本身只比隨機好 0.5～2 點且逐年不穩。
- 「營收加速 -20%＋空頭不買」回撤小很多（-16%），但 2023 輸 v2，過不了換版關卡；和「賺 20% 加碼」一起列為 2027-01 季度檢討的候選。
- 這次發現 `walk_forward_test.py`、`pead_portfolio_test.py` 在換成 v2 後會被預設版本蓋掉變體，已改成明確指定 `version="v1"`。
