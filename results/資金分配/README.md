## 閒置現金怎麼用（`idle_cash.txt`，腳本 `scripts/idle_cash_account_test.py`）

做法是把各份的名目比例加大（加起來超過 100%），實際買進仍受手上現金限制，不借錢。這個比較表從 2023-01 開始跑，v6 是 +255.4%。

| 做法 | 全期 | 前半 | 後半 | 平均現金 |
|---|---|---|---|---|
| A v6（30／30／40） | +255.4%／-19.1% | +65.4% | +115.2% | 37% |
| B 處置股每筆 5% → 7.5% | +313.8%／-19.8% | +92.0% | +115.7% | 31% |
| C 三份都放大 1.2 倍 | +330.0%／-23.8% | +81.9% | +136.8% | 25% |
| D 三份都放大 1.4 倍 | +359.0%／-25.7% | +100.8% | +129.0% | 17% |
| E 放大 1.2 倍＋處置股每筆 6.25% | +395.3%／-23.7% | +102.8% | +144.6% | 22% |
| F 只放大中長線（45／45／40） | +296.3%／-24.7% | +82.0% | +118.4% | 19% |
| G 只放大處置股（30／30／60） | +390.1%／-27.0% | +89.8% | +158.4% | 27% |

- 把閒錢用掉，報酬和回撤大致一起放大（C、D、F、G 回撤到 -24%~-27%，接近 -28% 的上限），等於只是加大風險，不是白賺。
- 只有 B（處置股每筆加大）回撤幾乎不變（-19.8%），但 2026 年反而輸（+59.0% 對 +64.9%），而且處置股每筆變成總資金 3%，容量問題更大。
- 結論：現在不改。這和「每筆放大 1.25 倍」是同一類問題，照 2027-01 季度檢討的約定，等 v6 實際跑出成績再看。
