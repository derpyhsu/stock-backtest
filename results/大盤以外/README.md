# 大盤以外的報酬來源（2026-11-26）

Derpy 的需求：大盤的漲幅已經靠定期定額 ETF 拿到，另外要「不靠大盤漲」也能持續賺的策略。

## 測過的

| 做法 | 結果 | 檔案 |
|---|---|---|
| v2 持股用台指期避險（以加權指數近似、每年扣 3.5% 逆價差） | 2023-04～2026-11 年化 +6.3%、回撤 -23.7%、賺錢月 56%（不避險年化 +25.6%）。和大盤月報酬相關從 0.65 降到 0.10。v2 的報酬大部分是大盤給的，純超額一年約 5～6%，而且回撤不小 | `scripts/hedged_v2_test.py`、`hedged_v2.txt` |
| 除息前卡位、參加除息、除息後等填息（7,859 筆事件） | 扣成本全部為負。除息前 10 天買、前 1 天賣只比隨機多 +0.5 點，不夠付成本。高息股（>=5%）除息日買抱 40 天比隨機少 3.2 點，「填息行情」不存在 | `scripts/exdividend_test.py`、`exdividend.txt` |
| 強勢股隔天開盤放空、收盤回補，做成帳戶 | 之前每筆 +0.26～0.32% 的平均，是 84% 的日子賺 +1.5%、16% 的日子（當天又收漲停）賠 -6%，而且假設漲停價買得回來。改成鎖漲停買不回、隔天開盤補，帳戶年化 -35%～-58%；加盤中停損 2%～5% 也一樣是負的。這個優勢是承擔軋空風險的補償，**不可用**（更正 11/25 的結論） | `scripts/short_fade_account_test.py`、`short_fade_account.txt` |

## 網路和 GitHub 上找到、還沒測的（都需要新資料）

- 第二次處置股（GitHub j1998719/twse-research：每筆 +4.25%、勝率 69%，作者自己說流動性條件是事後找的、還沒驗完）。需要證交所、櫃買的處置公告清單。2026-08-10 處置規則改過。
- 現金增資除權到撥券之間放空（政大論文 2000～2024，平均 +4.94%）。需要現增日程，而且要借得到券。
- 指數成分股調整（MSCI、0050、高股息 ETF）：需要手動整理名單，交易擁擠。
- 公開收購價差：一年只有幾件，沒辦法回測。
- 把手上的 ETF 出借（借券）：年收益約 0.1～0.3%，幾乎不用做事。
- 配對交易：台股論文扣成本後約 0～3%／年，弱。

研究的共同結論：散戶做市場中性，扣成本後一年大約 2～6%，而且常有賠錢的年份；回測年化 15～20% 的做多策略，避險後大多不剩多少。

GitHub（github.com、raw.githubusercontent.com）在這個環境的網路白名單外，開源程式碼讀不到，只看到搜尋摘要。

## 處置股：處置期間抱著（2026-11-26，目前最有希望）

資料 `data/disposition.csv`（`scripts/fetch_disposition.py`，證交所＋櫃買處置公告，2022 起 2,161 筆普通股事件）。
`scripts/disposition_test.py`（`disposition.txt`）、`scripts/disposition_account_test.py`（`disposition_account.txt`）。

規則：處置公告（收盤後）→ 處置第一天開盤買，處置最後一天收盤賣（中位數 10 個交易日）。開盤漲停不買、出場日跌停隔天賣；處置前 20 日均量 >= 500 張、股價 >= 10。沒有調過參數。

- 每筆（1,587 筆，已扣成本）：平均 +3.14%、中位 +1.75%、勝率 56%；每年 2022 -0.2%、2023 +2.7%、2024 +2.9%、2025 +2.3%、2026 +4.1%。比同期間隨機買股每年多 +1.8～+3.5 點。
- 晚一點買不會變差：首日收盤買 +3.78%、第二天開盤買 +3.83%。上市 +2.7%、上櫃 +3.5%。第一次處置 +3.0%、再次處置 +3.5%。
- 出關後才買（抱 5～10 天）是負的；加 -10% 停損平均降到 +1.8%。
- 帳戶（淨值每天用收盤價計）：每筆 5%、最多 20 檔 → 年化 +41.5%、回撤 -37.5%、最差月 -27%；每筆 2.5% → 年化 +20.4%、回撤 -20.1%、最差月 -13.9%。每年：-1%、+11%、+20%、+12%、+63%。和大盤月報酬相關 0.71。

風險與限制：
- 最差 5% 的交易 -21%，最差一筆 -44%（處置中連續跌停賣不掉）。
- 2022 空頭年約 0；2026 佔了大半獲利。仍然跟著大盤走，不是市場中性。
- 2026-08-10 處置規則改過，之後 159 筆平均只有 +1.17%（中位 +1.66%），樣本還少。
- 處置期間是分盤撮合（5～20 分鐘一次），大單或再次處置要預收款券；回測用日線開盤、收盤價，小資金影響不大，但要先確認券商下單方式。
- 一個 GitHub 開源研究（j1998719/twse-research）也回報第二次處置每筆 +4.25%，方向一致。

**併入模擬帳戶（v4，2026-11-26 Derpy 決定採用）**：三份資金各 1/3（營收加速、一年新高、處置股）。帳戶程式實測 2023-04～2026-11：+137.0%／回撤 -17.7%，每年 +15.8%、+23.4%、+14.4%、+44.6%；v3 +83.8%／-21.8%、v2 +115.1%／-27.6%、加權 +141.6%／-28.7%（`results/持有天數/v3_v4_backtest.txt`、`v4_trades.csv`）。先前「v3 佔 2/3＋處置股 1/3」的估算是 +175%，實際較低。處置股在帳戶裡 1,029 筆，平均每筆 +3.2%、最差 -48.8%。
