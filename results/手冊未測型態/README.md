# 手冊還沒測過的型態，和重讀文章後整理的新條件（2026-11-26）

做法和 `results/持有天數/` 一樣：訊號日收盤判斷、隔天開盤買（開盤漲停買不到）、抱 N 個交易日收盤賣，扣 0.6%。
「比隨機」＝同一天訊號的平均報酬，減同一天所有流動性股票（20 日均量 >= 500 張、股價 >= 10）的平均，每天一票。資料 2022-01～2026-11-25。
這些都是每筆交易的統計，還不是帳戶報酬；之前幾次的經驗是放進帳戶後會打折。

## 看得出來的事

- 贏的都是「趨勢已經對（或正要對）＋外資在買＋帶量轉強」。只看型態的左側條件（底部爆量、出量後不破底、窒息量平台）都輸隨機。
- 外資買超當過濾條件有幫助；投信買超、融資增加當過濾條件沒有幫助（一年新高＋融資 60 日大增：2025、2026 都輸）。
- 5～10 天沒有任何條件穩定贏。
