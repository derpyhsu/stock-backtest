# 族群短線輪動回測（2026-11-25）

問題：族群剛開始集體轉強時跟進、抱 3～10 天，能不能賺？三大法人能不能提早看出進出場？
資料 2022-08～2026-11，隔天開盤買（開盤漲 9.5% 以上買不到），扣 0.6% 成本，和同日隨機買股比「每天一票超額」。

族群兩種：證交所產業分類（太粗）、股價連動（每月用過去 120 天找相關係數最高的 10 檔，自動抓題材）。

## 結果

| 做法 | 5 日勝率 | 5 日超額 | 結論 |
|---|---|---|---|
| 產業轉強追全部 | 31% | -1.0% | 輸隨機 |
| 產業轉強買領頭 3 檔 | 33% | -1.2% | 輸隨機 |
| 連動族群轉強追全部 | 39% | -0.0% | 等於隨機 |
| 連動族群補漲股 | 40% | +0.1% | 等於隨機 |
| 產業轉強＋法人買 | 26% | -1.4% | 輸隨機，2025、2026 更差 |
| 連動轉強＋法人買 | 39% | -0.1% | 等於隨機 |
| 法人先買、股價未動（提早） | 39% | +0.1% | 等於隨機 |
| 族群法人連 2 天賣超就出場 | 37～40% | ±0.2% | 和固定天數差不多 |

- 族群已經轉強才追，平均輸隨機或打平；法人買超確認、法人先買提早進場都沒有比隨機好，年份之間也不穩定。
- 短線勝率只有 3～4 成：抱 3～5 天的平均漲幅，大多被一進一出 0.6% 成本吃掉。
- 沒放進選股。限制：日資料看不到盤中；題材族群用股價連動近似，新聞定義的題材無法不偷看未來地回測。

腳本：`scripts/sector_momentum_test.py`（族群價格）、`scripts/sector_flow_test.py`（加法人）。明細：`sector_momentum.txt`、`sector_flow.txt`。
