## 看到什麼

1. **長黑 K 放空沒有比隨便放空好。** +0.23% 對 +0.15%，前後半的正負也和對照一模一樣，賺到的是這兩個月大盤下跌，不是規則本身。
2. **開盤 5 分鐘順勢做多是負的**，前後半都是 -0.72%，勝率 24%。做空版也是負的。
3. **有差別的是選股，不是進場方式。** 昨天漲停的股票隔天放空，未扣成本 +1.26%，是全部股票（+0.69%）的將近兩倍；

限制：放空沒有檢查券源和平盤下能不能賣；59 天裡大盤單邊下跌；長黑 K 的定義影片沒講清楚，這裡自己定了兩種。
